运行 CloudSim 示例
-----------------

要运行 CloudSim 示例，您需要执行以下步骤：

在 Windows 中：

1. cd <CLOUDSIM 包路径>\jars
2. java -classpath cloudsim-<版本>.jar;cloudsim-examples-<版本>.jar org.cloudbus.cloudsim.examples.CloudSimExample<示例编号>

在 Unix/Linux 中：

1. cd <CLOUDSIM 包路径>/jars
2. java -classpath cloudsim-<版本>.jar:cloudsim-examples-<版本>.jar org.cloudbus.cloudsim.examples.CloudSimExample<示例编号>

您需要替换：

<CLOUDSIM 包路径> - 您解压 CloudSim 包的目录路径
<版本> - 下载的 CloudSim 包的版本
<示例编号> - 您要运行的示例的编号


CloudSim 示例源代码
-----------------

您可以在 <CLOUDSIM 包路径>/examples/org/cloudbus/cloudsim/examples/ 中找到示例的源代码


编译和运行示例
---------------

要编译和运行示例（例如 org.cloudbus.cloudsim.examples.CloudSimExample1），您需要执行以下步骤：

在 Windows 中：

1. cd <CLOUDSIM 包路径>
2. javac -classpath jars\cloudsim-<版本>.jar;examples examples\org\cloudbus\cloudsim\examples\CloudSimExample1.java
3. java -classpath jars\cloudsim-<版本>.jar;examples org.cloudbus.cloudsim.examples.CloudSimExample1

在 Unix/Linux 中：

1. cd <CLOUDSIM 包路径>
2. javac -classpath jars/cloudsim-<版本>.jar:examples examples/org/cloudbus/cloudsim/examples/CloudSimExample1.java
3. java -classpath jars/cloudsim-<版本>.jar:examples org.cloudbus.cloudsim.examples.CloudSimExample1


编译和运行 power 包中的示例
--------------------------

要编译和运行示例（例如 org.cloudbus.cloudsim.examples.power.planetlab.LrMc），您需要执行以下步骤：

在 Windows 中：

1. 从 http://www.ee.ucl.ac.uk/~mflanaga/java/ 下载 Michael Thomas Flanagan 的 Java 科学库
2. 将 flanagan.jar 复制到 <CLOUDSIM 包路径>/jars/
3. cd <CLOUDSIM 包路径>
4. javac -classpath jars\cloudsim-<版本>.jar;jars\flanagan.jar;examples examples\org\cloudbus\cloudsim\examples\power\planetlab\LrMc.java
5. java -classpath jars\cloudsim-<版本>.jar;jars\flanagan.jar;examples org.cloudbus.cloudsim.examples.power.planetlab.LrMc

在 Unix/Linux 中：

1. cd <CLOUDSIM 包路径>
2. chmod +x ./install-flanagan.sh
3. ./install-flanagan.jar
4. javac -classpath jars/cloudsim-<版本>.jar:jars/flanagan.jar:examples examples/org/cloudbus/cloudsim/examples/power/planetlab/LrMc.java
5. java -classpath jars/cloudsim-<版本>.jar:jars/flanagan.jar:examples org.cloudbus.cloudsim.examples.power.planetlab.LrMc


CloudSim 示例说明
----------------

以下是每个示例的功能说明：

CloudSimExample1.java : 展示如何创建一个包含一个主机的数据中心，并在其上运行一个云任务。

CloudSimExample2.java : 展示如何创建一个包含一个主机的数据中心，并在其上运行两个云任务。
			云任务在具有相同 MIPS 要求的虚拟机中运行。这些云任务将花费相同的时间来完成执行。

CloudSimExample3.java : 展示如何创建一个包含两个主机的数据中心，并在其上运行两个云任务。
			云任务在具有不同 MIPS 要求的虚拟机中运行。根据请求的虚拟机性能，云任务将花费不同的时间来完成执行。

CloudSimExample4.java : 展示如何创建两个各包含一个主机的数据中心，并在其上运行两个云任务。

CloudSimExample5.java : 展示如何创建两个各包含一个主机的数据中心，并在其上运行两个用户的云任务。

CloudSimExample6.java : 展示如何创建可扩展的仿真。

CloudSimExample7.java : 展示如何暂停仿真。

CloudSimExample8.java : 展示如何在运行时添加实体。

network: 此包包含有关如何运行带网络仿真的示例。

power: 此包包含有关如何使用 CloudSim 的功耗感知功能的示例。
